- **Each outward send carries one idempotency key, so the same message can never send twice.** Every Windy Mail send and Windy Text message now carries a key made from the chat message that led to it. Once Windy Mail (#275) and Windy Text (#125) honour it, a repeat gets the first result back instead of a second send. If Mail can't tell whether the first try went, the agent does not resend: it says to check the Sent folder (the existing sentence). Sends with no chat message behind them (scheduled jobs) are unchanged.
