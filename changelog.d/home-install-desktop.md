- **`windy home install --ticket -`: Windy Word's desktop door (DARK until the Hub's desktop door is on).** The installer makes this computer's agent key and prints it first as `{"event":"kid",...}`. It then reads `<handover_id>.<pickup_code>` from STDIN only (never argv, the environment, a file or a log), showing the seconds while it waits up to 15 minutes. It redeems the pickup and the memory with the code plus a signed proof by this computer's key. The pending platforms are shown while the Hub finishes. Then it registers the key first and brings the agent home, the same as every other door. The code, the bootstrap token and the proofs are never printed or stored.
