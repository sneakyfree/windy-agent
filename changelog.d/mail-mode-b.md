- **Windy Mail can use the short agent token (off by default).** With `WINDY_MAIL_EPT_AGENT=1`, every Windy Mail request (sending, the inbox, the mailbox facts) carries the agent's short EPT+agent for `windy-mail` and a fresh DPoP proof, instead of the 365-day passport token. If Mail refuses it (401), or no token can be minted, the agent uses the old credential once, until the old token stops on 2026-12-15. With the switch on, the agent's mailbox works without the long token at all.
