- **An agent you brought home remembers you, whatever folder it starts from.** Its memory file was found relative to the folder a command ran in, so `windy home` could put the handed-over memory in one folder while the agent, started from another, opened an empty one: it greeted you as a stranger and never answered your question. Now every part of Windy Fly finds the memory in one place: the agent's own state folder (`~/.windy`, or `WINDY_STATE_DIR`). Agents running today keep the file they already use, and nothing is moved, merged or deleted. `windy home` prints where it put the memory. An agent brought home never gets the "I just hatched" welcome. For a brand-new agent, the welcome no longer replaces the answer: the same reply also answers your first message.
