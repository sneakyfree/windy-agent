- **After a sleep, your agent answers from one place only.** A laptop that slept longer than 90 seconds lost the agent's claim at Windy Mind and never took it back, so a second copy of the agent could start and both would answer you. Now the agent claims it again as it wakes, before answering anything that arrived meanwhile. If another copy has taken over, this one stops answering and says once: "Another copy of your agent has started answering you, so I've stopped answering from here." It takes over again by itself when that copy stops, answering only new messages. If Windy can't be reached for 10 minutes after a wake, it says once "I can't reach Windy right now, so I'm pausing until I can.", keeps your messages, and answers them when Windy is back.
