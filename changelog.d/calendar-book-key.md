- **A retried booking returns the first booking, not "just taken".** `book_appointment` used to send a new random key on every call, so a retry (a timeout, or the model asking twice) looked like a second booker to Windy Calendar. The key is now the same for the same booking: this agent's passport + the start time + the booker's email (lowercased). Nothing else goes into it, as Calendar asked.
