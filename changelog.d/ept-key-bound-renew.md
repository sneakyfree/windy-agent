- **Ready for a passport token that lasts a day and belongs to one computer.** When Eternitas starts handing an agent's key a 24-hour passport token (off today), your agent renews it by itself at half its life, checked every 15 minutes; it keeps no copy of such a token on disk and removes the older copies of the year-long one; and if Eternitas says the key behind the token has ended, the agent stops only when that is the key this computer uses now. Nothing changes until Eternitas turns that on.
- **An agent that holds its own key never renews with your Windy sign-in.** Whatever the key call returns (a refusal, Eternitas being busy or down, a timeout, or a signing error on this computer), the agent does not quietly fetch a year-long passport token with the sign-in still saved on that computer. If the key is refused (for example after the agent moved to another computer), it stops and says why; to use it there again, pair it again. If Eternitas was only busy, it asks again by its key at the next check, a few minutes later.
