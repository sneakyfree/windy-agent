- **`windy home pair` handles its edge cases the way Hub's #700 review asked.** If a `windy bring-home` move is partway done, it says to finish that with `windy bring-home`. Ctrl-C at the cloud-link question cancels with "Nothing was changed". A Ctrl-C while the key registers keeps the key, so the next run finishes the move. Eternitas being unreachable gets the plain "isn't running anywhere right now" line instead of "Eternitas didn't accept this computer's key". The pending marker records the memory outcome, so a resumed run reports the memory truthfully. The memory line names where the memory was saved.
- **`windy bring-home` says where the agent is when the Hub answers `already_external`** (home handover 1.1): it runs on another computer, its last move didn't finish, or it may be running elsewhere (when the Hub can't tell). Each case points to `windy home pair`.
