- **Windy never sends a sign-in or a token to a non-https hub address.** `WINDY_HUB_URL` must be an `https://` address; plain `http://` is accepted only for this computer (localhost, 127.0.0.1, ::1). Any other value stops every hub call before a request is made: `windy login`, hatching, `windy bring-home` (now checked before the sign-in and the key change, so nothing is changed), and Your Windy's plan read. The person sees "WINDY_HUB_URL isn't an https:// address, so Windy won't send a sign-in or a token to it. Use https:// (http:// is allowed only for localhost)." An empty `WINDY_HUB_URL` now means the default address. The address itself is never logged.
