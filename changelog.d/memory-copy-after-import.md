- **No plaintext copy of the agent's memory is left behind after a move** (Hub, after Connect lab #1). `windy home pair`, `windy home install` and `windy bring-home` used to keep the downloaded memory (`memory-<id>.ndjson`) next to the database for good, so it outlived the owner's deletes. Now the copy is zeroed and removed once the import succeeds. It stays (0600) only when nothing was imported (a hash or count mismatch, an unknown format, or a failed import), with one log line naming the file and the reason, never its content.
