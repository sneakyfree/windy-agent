- **No plaintext copy of the agent's memory is left behind after a move** (Hub, after Connect lab #1). `windy home pair`, `windy home install` and `windy bring-home` used to keep the downloaded memory (`memory-<id>.ndjson`) next to the database for good, so it outlived the owner's deletes. Now the copy is zeroed and removed once a VERIFIED import succeeds (its declared hash and count match). It stays (0600) when the import is not proven: a hash or count mismatch, an unknown format, a failed import, or an archive that declares no hash or count, with one log line naming the file and the reason, never its content.
