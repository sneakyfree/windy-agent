# Strand history: plans and gap analyses that lived only on Windy 0

These files were working papers of the Windy Agent lane. Until 2026-10-21 they existed only on the Windy 0
machine (`~/windy-orchestra/specs` and the lane's scratch folders), outside git. They were copied off before
that machine was cleaned and are kept here so nothing about the strand lives outside the repo.

The living master plan is [`docs/strand/STRAND_V2.md`](../STRAND_V2.md) (executable scorecard: `tests/strand`).
These are history, not instructions:

- `WINDY_AGENT_ACCESS_STRAND_v0_2026-10-06.md`: the access gene draft (became N9, `docs/strand/AGENTS_HANDS_N9.md`).
- `WINDY_FLY_STRAND_TO_GREEN_PLAN_2026-10-10.md`: the waves plan that took the strand to green.
- `WINDY_FLY_WAVE5_STRAND_V2_PLAN_2026-10-11.md`: the plan for strand v2 as an executable scorecard.

Gap analyses and reports (same origin):

- `docs/audit/dna-gap-2026-10-10/`: the five-part DNA gap analysis against master 500aa13 and its HTML report.
- `docs/audit/gap-report/`: the four-column gap report shown to Grant (10-17 and 10-18 versions), with its data and
  build script.

Machine paths were replaced with placeholders; nothing else was edited.

## Words (Grant, 2026-10-21)

These dated papers use older words. Read them with today's:
- **Doorway:** where a person starts making an agent. Windy's are the phone app, the desktop Windy Word app and Windy Accounts' hatch page. windyfly.ai is not a doorway.
- **Birth Canal:** the one path every Windy agent is born through, the hatch ceremony in **Windy Accounts**. The old papers say "the hub", "hatch hallway" or "one hallway".
- **Eternitas Registry:** at the end of every Birth Canal it issues the birth certificate, passport and Integrity Index.
- **Windy Accounts** is the software. "The Hub lane" is the Claude session that runs it. Never "the hub" for the software.

Code names stay as they are (`hub_hatch.py`, `tests/test_one_hallway.py`).
