### Top 5 gaps
1. **Drift detection never fires in production.** The 24h job snapshots before it checks (main.py:61 → versioning.py:250-253; probe B'). `detect_drift` also ignores who made the change, so the user's own slider changes are reported as agent drift.
2. **Drift never reaches the user.** The `drift_alert` key (versioning.py:211) is read by nothing, and the Personality page has no drift, history or rollback controls.
3. **Golden tests and regression checks run on nothing.** No code writes `eval_results.golden_tests`, most promoted skills are text playbooks the sandbox can't execute, and there is no pass/fail history or user alert.
4. **Event logging covers 3 of the 9 spec'd types.** memory.write, skill.evaluate, cost.log, intent.surface, conflict.detect and matrix.message are never emitted, and console logs aren't JSON.
5. **The version line doesn't match the strand.** The v1.0.0 tag (2026-03-26) was followed by 0.6.x/0.7.x releases, and the CHANGELOG has no 1.0.0 and reuses older version numbers. On the ecosystem side, the largest gaps are Matrix encryption doing nothing in the default install, no Cloud file retrieve, and no K3 directory registration.
