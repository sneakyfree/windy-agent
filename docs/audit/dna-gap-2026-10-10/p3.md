### Top 5 gaps
1. **The skill sandbox is unsafe.** It runs as the same uid with full filesystem and network access. The regex safety gate is easy to bypass and only runs after the code has already executed. JS skills inherit the parent's full environment, secrets included. Exposure today is limited to executable skills sent over UDS and golden tests.
2. **Conflicts are not resolved before overwriting.** `upsert_node` saves the new value anyway, "keep old" can't restore the old one, and the user is never asked in chat.
3. **The intent LLM detector never runs.** An unescaped-brace `.format()` KeyError is silently swallowed, so no `inferred_from_chat` intents are ever created and the Intent Inbox is always empty.
4. **Intent decay never runs.** `decay_intents` has no callers, so stale goals never lose priority (C3.12).
5. **Budget accounting gaps.** Over-budget is a hard block with no "proceed anyway?" option. Max-subscription calls appear to be priced at list and counted toward the $5/day default. Mind "auto" turns estimate $0 before the call.
