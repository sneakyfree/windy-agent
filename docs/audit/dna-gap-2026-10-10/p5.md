4. **The Phase 7 gateway features have zero tests:** discovery, multi-key, OpenRouter OAuth PKCE (no `state` parameter) and validation. The full key is also copied into the non-0600 `providers.json`.
5. **`/api/mode` does nothing in practice.** The loop never passes the stored mode into the prompt. Related: the drift detector flags changes the user made, and skill promote skips the 3-gate check.
