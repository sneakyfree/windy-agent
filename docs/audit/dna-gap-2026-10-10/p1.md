### Top 5 gaps
1. **Mode switching does nothing.** `/mode` says it switched but stores nothing (commands/core.py:1563-1570), the loop never passes `mode` to the prompt (loop.py:823), and the bridge's `agent_mode` value is never read. Focused and neutral modes can't be reached.
2. **sqlite-vec is listed but never used.** It is a dependency and the README says it powers memory, but it is never loaded. Semantic recall is plain Python cosine math over stored blobs, and only with the opt-in `[semantic]` extra, which is off by default.
3. **No overall prompt size cap, and the config knobs for it do nothing.** `agent.max_context_tokens`, `max_response_tokens`, `temperature` and `memory.max_episodes_per_context` are never read; sliders decide those values instead. There are also four different default models across toml, config.py, .env.example and the loop.
4. **The first message is lost to the welcome.** On first contact the canned welcome returns early (loop.py:785-794), so the user's first message never reaches the LLM and facts in it (e.g. "My name is …") never become memory nodes.
5. **Two "atomic" spec items aren't atomic, and three behaviours lack tests.** MEDIUM write batches commit item by item rather than in one transaction (write_queue.py:161-168). SQL-string migrations aren't atomic because `executescript` commits implicitly (database.py:818). There are no tests for in-session recall, a CLI chat turn, or the full HIGH > MEDIUM > LOW order.

Scratch scripts are in <a temporary scratchpad, since deleted> (p0check.py, p0cli.py).
